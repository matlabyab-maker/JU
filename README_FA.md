# JU — نسخه سبک پرواز Junkers Ju 52

این یک نمونه اولیه قابل ویرایش Godot 4 است که برای شروع نسخه سبک اندروید ساخته شده است.

## اجرا
1. Godot 4.3 یا نسخه جدیدتر را باز کنید.
2. از Project Manager گزینه Import را بزنید و فایل `project.godot` را انتخاب کنید.
3. پروژه را اجرا کنید.

## کنترل‌ها
- W / فلش بالا: اوج‌گیری
- S / فلش پایین: پایین آمدن
- A/D یا فلش چپ/راست: گردش
- Shift: افزایش سرعت
- Ctrl: کاهش سرعت
- روی صفحه: دکمه‌های لمسی

## نکته مهم
- هواپیما در این نسخه با قطعات سه‌بعدی ساده‌شده ساخته شده است تا پروژه بدون فایل‌های حجیم خارجی باز شود؛ این مدل، اسکن یا مدل دقیق تاریخی Ju 52 نیست.
- کوهستان به‌صورت رویه‌ای تولید می‌شود و بافت‌های حجیم خارجی ندارد.
- هنوز APK نهایی ساخته نشده است؛ برای خروجی اندروید باید Android SDK و قالب‌های Export در Godot نصب و تنظیم شوند.
- هدف اولیه حجم APK حدود 70 MB است، اما حجم واقعی پس از Export باید اندازه‌گیری شود.
- این نسخه نمونه اولیه پرواز است؛ صدا، مأموریت، دشمن و مدل تاریخی دقیق در آن گنجانده نشده‌اند.
